This repository contains a 3D map extension and Python script that visualizes trajectories generated from CrowdES.


### 💻 Requirements
- Ubuntu system (tested on 18.04)
- Carla 0.9.15


### ⚙️ Installation
1. Download and uncompress [Carla 0.9.15](https://github.com/carla-simulator/carla/releases/tag/0.9.15/).

2. Download and uncompress the [CrowdES map extensions](https://github.com/InhwanBae/Crowd-Behavior-Generation/releases/download/v1.0-map/CrowdESMaps_0.9.15.tar.gz) from our [release page](https://github.com/InhwanBae/Crowd-Behavior-Generation/releases).
Then, put the map extensions in the CARLA root directory.

3. Make a Python virtual environment and install the required packages.
   ```bash
   conda create -n crowdes-vis python=3.10
   conda activate crowdes-vis
   pip install numpy pandas carla==0.9.15
   ```


### 🌏 Usage
1. Start Carla server:
   ```bash
   ./CarlaUE4.sh
   ```

<br>

2. Run our visualization script in another terminal:
   ```bash
   python run_trajsim.py --path path/to.csv --scene [scene_name]

   # Example
   python run_trajsim.py --path sample/hyang_0-crowdes-0.csv --scene hyang
   python run_trajsim.py --path sample/crowds_zara01-crowdes-0.csv --scene zara
   ```

> [!NOTE]
> You can control the length of the trajectory to be drawn using the `--draw_len` argument.
> ```bash
> python run_trajsim.py --path sample/hyang_0-crowdes-0.csv --scene hyang --draw_len -1  # draw all trajectory
> python run_trajsim.py --path sample/hyang_0-crowdes-0.csv --scene hyang --draw_len 10  # draw future 10 seconds
> ```

> [!TIP]
> You can enhance the UE4 visualization quality by typing `~` key in the Carla window to open the console and entering the following commands. You need to enter line by line in the console.
> ```python
> # Forces all meshes to use the highest LOD level
> r.StaticMeshLODDistanceScale 0
> r.SkeletalMeshLODBias -10
> foliage.ForceLOD 0
> r.ForceLOD 0
> 
> # Disable post-process effects for better visibility
> # (https://github.com/carla-simulator/carla/issues/7894)
> r.BloomQuality 0
> showflag.Emissive 0
> ```
>

3. You can use the trajectory generated by CrowdES.
   ```bash
   python trainval.py --model_config path/to/config.yaml --export
   
   # Example
   python export_csv.py --path ./configs/model/CrowdES_zara01.yaml --export
   ```
